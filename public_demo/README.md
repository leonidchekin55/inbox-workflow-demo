# Единая очередь — учебная веб-демонстрация

Статический сайт для демонстрации очереди обращений и шаблонов ответов. Все учебные примеры, изменения и черновики существуют только в памяти текущей вкладки, не сохраняются после обновления/закрытия и не отправляются на сервер или внешним сервисам. Реальные данные клиентов не вводить.

Мессенджеры, вебхуки, автоматические ответы, хранение, синхронизация и ИИ не подключены. Для реальной системы нужна отдельная защищённая разработка, согласование доступа и проверка ограничений сервисов.

Проверка: `npm test` (Node.js 18+). Статические файлы можно отдать без сборки; для Render статический каталог — корень проекта.
