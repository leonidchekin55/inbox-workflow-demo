# Демо: учёт обращений

Небольшой русскоязычный статический прототип для демонстрации учёта учебных обращений из нескольких каналов. Работает целиком в браузере без сервера, аккаунтов, аналитики и внешних запросов.

## Возможности

- Учёт учебных задач по каналу и номеру аккаунта, статусу и сроку; редактирование и удаление с подтверждением.
- Обзор открытых, просроченных и завершённых задач; просроченные отображаются первыми.
- Поиск, фильтры, учебные примеры и редактируемые шаблоны ответов.
- Сохранение в localStorage текущего браузера.

## Ограничения

Это демонстрация, не система хранения клиентских данных. Не вводите имена, телефоны, паспорта, документы и иную личную или конфиденциальную информацию. Записи видны пользователям устройства и могут исчезнуть при очистке данных браузера. Прототип не подключён к WhatsApp, Telegram или MAX, не читает сообщения, не вызывает ИИ и не отправляет данные, ответы или уведомления. Сроки отображаются только на странице. Совместная работа, серверное хранение, защита и резервное копирование не реализованы.

## Запуск и проверка

Откройте `index.html` в современном браузере. Разрешение сохранять данные зависит от настроек браузера. Автоматическая проверка основных сценариев (Node.js 18+):

```sh
node test.cjs
```

Проверка имитирует окружение браузера и не заменяет визуальную или кроссбраузерную проверку.

## Локальная учебная панель обращений

Дополнительно подготовлена отдельная локальная панель на Python 3.9+ и стандартной библиотеке. Для запуска на macOS откройте `Запустить.command`; либо выполните `python3 -m automation.launch`. Приложение слушает только `127.0.0.1`, использует случайный свободный порт и хранит фиктивные сообщения только в памяти. После остановки сервера записи исчезают.

Панель показывает учебную очередь по трём каналам и нескольким аккаунтам, шаблоны, редактирование черновика, копирование и ручные статусы. Приём настоящих обращений, сетевые вебхуки, отправка и ИИ не реализованы и не включены. Модуль `automation/provider_events.py` содержит изолированные функции проверки подписей и разбора поддерживаемых текстовых событий для будущей интеграции; они не соединены с сетью или рабочим хранилищем. Не используйте эту версию для реальных персональных или клиентских данных.

Проверки: `python3 -m unittest discover -s tests -v` и `node --check panel/app.js`.

## Визовый справочник

Откройте `visa-guide/index.html` в браузере. Справочник позволяет вести списки документов по стране и типу визы, записывать источник и дату проверки, искать сведения и редактировать шаблоны ответов. Исходные карточки стран пусты: актуальные сведения необходимо заполнить и проверить. Данные сохраняются в браузере на текущем устройстве; предусмотрен экспорт резервной копии. Описание и ограничения находятся в `visa-guide/README.md`.

## Подготовка ежедневных уведомлений

`automation/daily_alerts.py` содержит очередь, которая может учитывать первое принятое событие за день по выбранной группе, сохранять состояние и откладывать повторную попытку. Её используют локальный приёмник и почтовый обработчик. Реальные устройства и почтовый сервер пока не настроены. Для группировки по клиентам необходимо надёжное сопоставление идентификаторов. При неизвестном клиенте каждое уникальное событие создаёт отдельную запись, чтобы не скрывать обращения разных людей. Если результат отправки неизвестен, он остаётся на ручной проверке. Защита данных и проверка реальных устройств остаются необходимыми до использования.

## Приёмник, почта и Android

В `notification-hub/` находятся локальный приёмник, панель и настраиваемая почтовая доставка. На Mac панель можно запустить через `notification-hub/Запустить.command`. Источники Android-клиента и шаблон ручной сборки находятся в `android-alerts/`. APK пока не собран, а приложение не проверено на телефоне. Для реальных устройств потребуется настроить защищённый HTTPS-канал, зарегистрировать устройства и проверить сценарии каждого мессенджера. Почта настраивается отдельно, до настройки сообщения не отправляются. Подробности и ограничения приведены в README соответствующих папок.
