# Визовый справочник

Откройте `index.html` двойным щелчком в браузере на своём компьютере. Для стабильного доступа открывайте файл из одной и той же папки и в одном браузере. Интернет не нужен.

Раздел «Страны и визы» изначально пуст. Добавьте страну, тип визы, документы, сроки, биометрию, место хранения списка, источник и дату проверки. Сведения заполняет и проверяет владелец справочника. Готовых правил для конкретных стран здесь нет.

В разделе «Шаблоны ответов» есть заготовки по распространённым вопросам. Их можно изменить, дополнить, сохранить и скопировать вручную. Перед использованием проверьте содержание и заполните поля в квадратных скобках.

Данные сохраняются в хранилище текущего браузера на этом устройстве. При очистке данных браузера или смене браузера записи могут исчезнуть. Кнопка «Сохранить копию» скачивает файл JSON для резервной копии или переноса. «Загрузить копию» полностью заменяет текущие записи после подтверждения. Держите копию в доступном только вам месте.

Справочник предназначен для общих рабочих материалов. Учётные данные, клиентские документы и личные данные в нём хранить не следует. Автоматического поиска по папкам компьютера здесь нет, поле расположения заполняется вручную.
